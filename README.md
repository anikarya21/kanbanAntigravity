# Kanban Board Application

An MVP Kanban web application with a single board, five renameable columns, drag-and-drop card movement, and in-memory state.

## Project Structure

- `frontend/` - Next.js client application

## Getting Started

Navigate to the frontend directory and install dependencies:

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the board.
